# 量化因子筛选器

## 工作流程

### 第一步：确定参数
| 输入 | 选项 | 默认 |
|------|------|------|
| 选股池 | 沪深300/中证500/中证1000/全A/自定义 | 中证800 |
| 因子 | 全部6个或特定 | 全部 |
| 因子权重 | 等权或自定义 | 等权 |
| 行业约束 | 行业中性或不约束 | 行业中性 |
| 结果数量 | 前N只 | 前20只 |

### 第二步：因子得分计算

| 因子 | 主要指标 | 默认权重 |
|------|---------|---------|
| 价值 | 盈利收益率、PB倒数、FCF收益率、EV/EBITDA | 1/6 |
| 动量 | 12-1月价格动量、盈利预期修正动量 | 1/6 |
| 质量 | ROE、盈利稳定性、低杠杆、应计质量 | 1/6 |
| 低波动 | 已实现波动率（1年）、Beta、下行偏差 | 1/6 |
| 规模 | 市值（越小得分越高） | 1/6 |
| 成长 | 营收增速、盈利增速、利润率扩张 | 1/6 |

### 第三步：综合得分
`综合得分 = Σ(因子权重 × 因子得分)`

## 因子详情

- **价值**：盈利收益率(30%) + PB倒数(20%) + FCF收益率(30%) + EV/EBITDA(20%)
- **动量**：12-1月价格动量(50%) + 盈利修正(30%) + 换手率动量负向(20%)
- **质量**：ROE(30%) + 盈利稳定性(20%) + 低杠杆(25%) + 应计质量(25%)
- **低波动**：已实现波动率(40%) + Beta(30%) + 下行偏差(30%)
- **规模**：总市值(100%)，小市值得分高
- **成长**：营收增速3年CAGR(30%) + 净利增速(30%) + 利润率扩张(20%) + 一致预期(20%)

## A股因子特殊性

- 低波动异象非常显著（年化超额6-8%）
- 价格动量不稳定，需结合盈利修正
- 低换手率是独特的有效负向因子
- 行业中性约束很重要
