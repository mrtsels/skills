# wencai 市场总结工作流（已验证）

当 thsdk `market_data_index` 和 akshare 都因权限/网络失败时，**wencai_nlp 是可信的数据源**。

## 验证过的查询

### 大盘指数

```python
resp = ths.wencai_nlp("上证指数 深证成指 创业板指 今日涨跌幅")
```

返回每个股票的今日涨跌幅。如为空则改用 `klines(code, interval="day", count=3)` 取每日收盘计算涨跌幅。

### 行业板块排名

```python
resp = ths.wencai_nlp("今日申万行业涨跌幅排名")
```

注意：**返回的是个股级数据**，每行一只股票，带行业名称和行业内排名。需人工归纳。
关键字段：`最新价`、`涨跌幅:前复权[YYYYMMDD]`、`股票简称`、`行业简称`

### 行业涨幅前三板块

```python
resp = ths.wencai_nlp("今日行业板块涨幅排名前三")
```

每3行为一个板块（第1/2/3名），适用于快速扫描哪些板块活跃。

### 资金流向

```python
resp = ths.wencai_nlp("今日行业主力净流入排名")
```

字段：`主力资金流向[YYYYMMDD]`（数值，单位元）、`股票简称`、`行业简称`
主力净流入高的行业通常是当日主线。

## 字段解析要点

1. 列名包含日期编码，**不要按列名字符串取值**，用位置或模糊匹配
2. `涨跌幅` 列名可能是 `涨跌幅:前复权[20260720]`
3. 主力资金数值格式为 `3.0395341139999993E7`（科学计数法，即 3,040万）
4. 行业排名格式为 `1/54`，表示该股在其行业中排第1/共54

## 典型输出解析

```
百普赛斯 +8.71%  行业:生物制品  排名:1/54  主力流入:+3040万
```

归纳为板块结论：**生物制品全线爆发，54只成分股中51只收红**。
