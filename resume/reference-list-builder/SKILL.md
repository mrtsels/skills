# Reference List Builder

Use when the user needs to prepare a professional reference list.

## Standard Reference Format

Name, Title
Company
Email | Phone
Relationship (Former Manager, Colleague, etc.)
Years known

## Reference Selection Criteria

- Former managers (strongest)
- Senior colleagues or mentors
- Clients (for consulting roles)
- Professors (for recent graduates)
- 3-5 references standard
- Ask permission before listing

## Reference Prep Package

For each reference, prepare:
1. The job description they will speak to
2. Key points to emphasize about you
3. Specific projects or achievements to mention
4. Your current resume for context
