# Executive Resume Writer

Use for C-suite, VP, and senior leadership roles.

## Key Differences from Standard Resumes

- Focus on strategic impact, not tactical tasks
- Emphasize P&L responsibility and business outcomes
- Board-level communication and stakeholder management
- Organizational transformation and culture change
- Revenue, profitability, and growth metrics

## Executive Resume Structure

1. **Executive Summary**: brand statement, key differentiators (3-5 lines)
2. **Core Competencies**: 8-12 strategic skills (2-column list)
3. **Professional Experience**: reverse chronological, 5-7 bullets per role
4. **Board Positions**: if applicable
5. **Education + Executive Education**: include leadership programs
6. **Professional Affiliations**: board memberships, industry associations

## Executive-Level Metrics

- P&L responsibility size ($X revenue, $Y budget)
- Team size and org structure (direct reports, total org)
- Revenue growth or turnaround percentages
- M&A experience (deal size, integration)
- Board presentations and investor relations
- Industry recognition and awards

## Technical Roles (SWE / PM)

Use for software engineering, PM, data science, and other technical roles.

## Key Differences from Standard Resumes

- Technical skills section prominent (languages, frameworks, tools)
- GitHub/portfolio links included
- Projects and side work valued
- Open-source contributions count as experience
- System design and architecture experience highlighted

## Section Order for Tech Roles

1. Summary (optional, 2-3 lines max)
2. Technical Skills (grouped: languages, frameworks, tools, cloud)
3. Experience (with tech stack mentioned per role)
4. Projects (including side projects, open source)
5. Education (can be lower for experienced hires)
6. Publications / Talks (if applicable)

## Tech Resume Requirements

- Include specific technologies in experience bullets
- Quantify impact (performance improvements, scale, users)
- Mention team size and collaboration patterns
- Include system design ownership
- List relevant certifications
- Keep to 1-2 pages

## Creative & Portfolio Roles

Use for design, creative, and artistic roles where visual presentation matters.

## The Balance

Creative roles need two versions:
1. **ATS Resume**: text-only, single column, no graphics (for HR systems)
2. **Portfolio Resume**: visual, designed, with work samples (for hiring managers)

## Visual Resume Guidelines

- Moderate design elements (color accent, clean layout)
- Typography hierarchy is critical
- Include portfolio link prominently
- Work samples > description
- Process documentation valued

## ATS Version

- Follow standard ATS rules
- Mention visual tools and software
- Include portfolio URL in contact section
- Describe visual work with words
- Keep section headers standard
