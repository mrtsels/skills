# Resume Role Optimizer

Trigger: Use when tailoring a resume for a specific role type — executive/C-suite, technical (SWE/PM), or creative/portfolio — each with its own key differences, section order, and metric requirements.

## 1. Role Adaptation Workflow

Apply these steps before touching the role-specific tracks below:

1. **Identify role type & audience** — executive recruiter/board, hiring manager, or HR/ATS scanner determines template and section order.
2. **Extract keywords** — pull hard skills, tools, and role-specific phrases from the job description; weave them verbatim into bullets.
3. **Select the track** — Executive, Technical, or Creative (below); use the Executive track for leadership hybrids like Engineering Manager or VP of Product.
4. **Reorder sections** — put the highest-signal content first per track conventions.
5. **Rewrite bullets** — convert task descriptions into outcomes using the track's metric requirements.
6. **Produce the ATS-safe variant** — plain text, standard headers, no graphics; keep the designed version for direct outreach.
7. **Verify** — length (1-2 pages), keyword coverage, no chronological gaps, contact info intact.

## 2. Executive / C-Suite Track

For C-suite, VP, and senior leadership roles. Audiences are executive recruiters and boards; signal is strategic impact.

### Key Differences
- Strategic impact over tactical tasks — what the org became, not what you did daily.
- P&L ownership, business outcomes, and org transformation front and center.
- Board communication, stakeholder management, and culture change as core evidence.

### Section Order
1. Executive Summary — brand statement + key differentiators (3-5 lines)
2. Core Competencies — 8-12 strategic skills (2-column list)
3. Professional Experience — reverse chronological, 5-7 bullets per role
4. Board Positions — if applicable
5. Education + Executive Education — include leadership programs
6. Professional Affiliations — board memberships, industry associations

### Metrics Required
- P&L scope: revenue ($X), budget ($Y)
- Team size and org structure (direct reports, total org)
- Revenue growth or turnaround percentages
- M&A activity (deal size, integration outcomes)
- Board presentations and investor relations
- Industry recognition and awards

## 3. Technical Track (SWE / PM / Data Science)

For software engineering, product management, data science, and similar roles. Audiences skim for stack fit and shipped impact.

### Key Differences
- Technical skills prominent: languages, frameworks, tools, cloud.
- GitHub/portfolio links included; projects and side work count as experience.
- Open-source contributions and system design/architecture ownership highlighted.

### Section Order
1. Summary — optional, 2-3 lines max
2. Technical Skills — grouped: languages, frameworks, tools, cloud
3. Experience — tech stack named per role
4. Projects — side projects and open source included
5. Education — lower for experienced hires
6. Publications / Talks — if applicable

### Metrics Required
- Specific technologies named inside experience bullets (not just the skills list)
- Quantified impact: performance improvements, scale, users
- Team size and collaboration patterns
- System design ownership
- Relevant certifications
- Keep to 1-2 pages

## 4. Creative & Portfolio Track

For design, creative, and artistic roles where visual presentation matters. Always ship two versions.

### The Dual-Version Rule
1. **ATS Resume** — text-only, single column, no graphics; for HR systems.
2. **Portfolio Resume** — visual, designed, with work samples; for hiring managers.

### Visual Guidelines
- Moderate design: one color accent, clean layout; typography hierarchy is critical.
- Portfolio link prominent; work samples beat descriptions; process documentation valued.

### ATS Version Rules
- Follow standard ATS rules (standard section headers, no tables/graphics).
- Mention visual tools and software by name.
- Include portfolio URL in the contact section.
- Describe visual work in words, not images.

## Pitfalls
- Don't reuse the same section order across tracks — recruiters pattern-match instantly.
- Don't bury P&L/scale numbers in executive or tech bullets; lead with them.
- Don't submit a designed resume as the ATS version — graphics strip out or garble.
- Don't omit tech stack from experience bullets; the skills list alone won't clear keyword screens.
- Don't pad executive resumes with tactical detail — boards want outcomes, not tasks.
- Don't exceed 2 pages on any track; 1 page for early-career technical roles.
- Don't leave the portfolio URL off the ATS variant's contact section.
- Don't skip workflow step 2 — keyword coverage is what gets past the scanner.
