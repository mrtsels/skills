# Portfolio Case Study Writer

Use when the user needs to create detailed portfolio pieces from resume experience.

## Case Study Structure

1. **Title and Role**: project name, your role, timeline
2. **Context**: company, team size, project goals
3. **Problem**: what was the challenge
4. **Approach**: your process and methodology
5. **Solution**: what you built or delivered
6. **Results**: metrics, outcomes, impact
7. **Reflection**: what you learned, what you would do differently

## For Different Roles

- **Design/UX**: include process (research, wireframes, iterations, final)
- **Engineering**: include architecture decisions, tradeoffs, tech stack
- **PM**: include strategy, stakeholder management, prioritization
- **Data Science**: include problem framing, methodology, model performance

## Rules

- Each case study is 1-2 pages
- Include visuals where possible (diagrams, screenshots, charts)
- Focus on your specific contribution
- Anonymize sensitive data
- Tell a story with a clear arc
