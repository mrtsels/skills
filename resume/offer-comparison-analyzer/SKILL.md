# Offer Comparison Analyzer

Use when the user has multiple job offers and needs help deciding.

## Analysis Components

1. **Total Compensation**: base, bonus, equity, benefits (monetized)
2. **Career Growth**: title, responsibility, learning, trajectory
3. **Culture Fit**: values, work style, team, management
4. **Location & Logistics**: commute, remote, relocation
5. **Long-term Value**: brand, network, exit opportunities

## Total Compensation Calculator

Total = Base Salary + Signing Bonus + (Annual Bonus % x Base) + Equity/Year + Benefits Value

- Benefits value: 401k match + insurance premiums paid + education budget + other perks
- Equity: value per year = total equity / vesting years
- Adjust for cost of living if locations differ

## Decision Framework

Weight each category (1-10) based on user priorities, score each offer (1-10), calculate weighted total. Present as a comparison table.
