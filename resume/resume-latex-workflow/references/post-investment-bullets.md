# Post-Investment / Financial Compliance Bullets

Domain: FOF post-investment lifecycle, valuation extraction, compliance document production.

## Pattern

```
Orchestrated/Managed + scope (dual FoF products, N+ sub-advisors) + action
(extracted/reconciled/produced) + data scope (N+ financial statements)
+ deliverable (N+ compliance documents per cycle) + specifics
(performance attribution, negative-news screening)
```

## Example Bullets

EN:
```
Orchestrated quarterly post-investment lifecycle for dual FoF products
covering 15+ sub-advisors; extracted valuation data from 30+ financial
statements across xls/pdf formats, produced 35+ compliance documents per
cycle including performance attribution and negative-news screening
```

ZH:
```
统筹两档FoF产品季度投后全流程，覆盖15+子投顾；提取30+份估值表财务
数据，每周期产出35+份合规文档
```

## Key Verbs

| Category | Verbs |
|----------|-------|
| Orchestration | Orchestrated, Managed, Coordinated, Oversaw |
| Extraction | Extracted, Reconciled, Aggregated, Compiled |
| Production | Produced, Authored, Generated, Compiled |
| Verification | Audited, Validated, Cross-referenced, Verified |
