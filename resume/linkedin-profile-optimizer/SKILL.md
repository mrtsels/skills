# LinkedIn Profile Optimizer

Use when the user wants to improve their LinkedIn profile for job searching.

## Key Areas

1. **Headline**: 220 characters, keyword-rich, value proposition
2. **About section**: story-driven, 3-5 paragraphs with keywords
3. **Experience**: sync with resume, but LinkedIn allows more conversational tone
4. **Skills**: 50 skills max, reorder by relevance, endorsements strategy
5. **Recommendations**: request strategy, who to ask, what to say
6. **Featured**: portfolio, articles, posts strategy
7. **Activity**: content sharing cadence, engagement strategy

## Optimization Rules

- Headline must work both for search and for humans
- About section: hook, story, skills, call to action
- Use industry keywords throughout
- Turn on Open To Work (selective visibility)
- Customize URL
- Add media to experience entries
