# 政策文档模板

## 政策基本信息表格

```
| 项目 | 内容 |
|------|------|
| 政策名称 | [完整名称] |
| 发文文号 | [文号，如"粤工信规字〔2024〕5号"] |
| 发布日期 | YYYY-MM-DD |
| 发文部门 | [发文部门全称] |
| 政策层级 | 省级/市级/区级规范性文件 |
| 原文链接（完整URL） | https://... |
| 官方来源 | [来源网站名称] |
```

## 条款引用格式

```
### [条款类型]（第X条）

**原文**：[逐字引用政策原文]
（依据：第X条）

> 注意/解读：[如有，可选]
```

## 系统关联分析格式

```
## 与系统的关联

| 系统功能 | 对接情况 |
|----------|----------|
| [功能名] | [已有/需补充/部分已有] |
```

## 文件命名规范

- 摘要文件：`序号-政策简称.md`
- 原文文件：`序号-政策简称-原文.md`
- 用 tab 缩进，使用 `-原文.md` 后缀区分

## 关键规则

### URL格式

**必须使用纯字符串URL** — ChatGPT默认输出markdown链接 `[text](url)` 格式，这在粘贴到Word/PDF/报告时丢失可追溯性。必须明确要求："原文链接（完整URL）后面直接写 https://... 不要用方括号包住"。

### 原文优先

**原文是首要产出，摘要只是辅助。** 当用户发来搜索结果，先保存为markdown文件，再写分析。不要先写分析等URL验证。|
