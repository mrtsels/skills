## 患者分类体系

所有患者为**女性、超重/肥胖、缺乏健身知识**。按三个维度分入 6 套计划：

| 计划 | 名称 | BMI | 设备 | 天数 | 核心特征 |
|------|------|-----|------|------|----------|
| A | 居家减脂入门·低频 | < 28 | 居家 | 2-3 | 全身训练，无器械/弹力带 |
| B | 居家减脂入门·中频 | < 28 | 居家 | 4-5 | 上下肢分化，弹力带进阶 |
| C | 健身房塑形入门·低频 | < 28 | 健身房 | 2-3 | 推/拉/腿 PPL，固定器械 |
| D | 健身房塑形入门·中频 | < 28 | 健身房 | 4-5 | 上下肢分化，自由重量入门 |
| E | 大体重·安全起步（居家） | ≥ 28 | 居家 | 2-3 | 全低冲击，坐姿/地面为主 |
| F | 大体重·安全起步（健身房） | ≥ 28 | 健身房 | 2-3 | 全固定器械，无自由重量 |

> 大体重不分频，统一低频起步（保护关节）。
> 新手首周建议低容量（减半组数/天数）。

## 出诊流程

### C1 — 打开模板

读取 `templates/patient-intake-template.md`，向患者一次性追问以下信息：

| 区块 | 字段 |
|------|------|
| 基本信息 | 年龄、身高(cm)、体重(kg) → 自动计算 BMI |
| 体能评估 | 体能水平（新手/初级/中级）、既往运动史、当前活动量 |
| 设备条件 | 居家 / 健身房；居家可用器械 |
| 时间可用性 | 每周天数（2-3 / 4-5）、每次时长（30-90min） |
| 健康筛查 | 关节不适、慢性病史、备孕/孕期/产后、饮食失调史、长期用药 |
| 目标设定 | 减脂 / 体成分重组、期望周期、参考目标 |

**追问原则：** 一次问完所有缺失参数，避免来回多次。

### C2 — 匹配计划

| 条件 | → 计划 |
|------|--------|
| BMI < 28 + 居家 + 2-3 天/周 | **A** |
| BMI < 28 + 居家 + 4-5 天/周 | **B** |
| BMI < 28 + 健身房 + 2-3 天/周 | **C** |
| BMI < 28 + 健身房 + 4-5 天/周 | **D** |
| BMI ≥ 28 + 居家 | **E** |
| BMI ≥ 28 + 健身房 | **F** |

在模板中填写匹配结果，供医生确认。

### C3 — 个性化调整

1. 复制对应 `plans/plan-*.md` → `outline.md`
2. 复制对应 `prompts/prompts-*.md` → `chatgpt-image-prompts.md`
3. 将患者姓名/日期填入封面
4. 填写评估数据（年龄、身高、体重、BMI、体脂估算）
5. 根据健康筛查标注注意事项
6. 根据体能水平微调首周容量（新手减半）
7. **不修改 `plans/` 下的源文件**

### C4 — 交付

- 医生审核 `outline.md` 和 `chatgpt-image-prompts.md`
- 医生确认后交付患者
- 在 TASKS.md 中更新交付记录

## 每次接诊的强制检查项

1. ✅ 打开前先读 `TASKS.md` 确认阶段
2. ✅ 所有患者变量已确认或标记为"待补充"
3. ✅ 训练计划符合渐进超负荷原则
4. ✅ 动作名称中英文标注完整
5. ✅ 医疗边界已遵守，免责声明已包含
6. ✅ 存在高风险指标时（BMI < 18.5 或 > 35、慢性病等）**明确标记**并建议医生审核
7. ✅ 图像提示词包含所有必备要素（风格/媒介/配色/构图/文字）
8. ✅ 完成后更新 TASKS.md 进度

## 语言规则

- 医生对话：**中文**
- 计划文件内容：**中文**（动作名首次出现附英文）
- 图像提示词正文：**英文**，中文注释说明用途

## 安全边界

- **绝不涉及：** 处方药、激素治疗、医学诊断
- **绝不提供：** 超出运动营养和生活方式范围的医学建议
- 每个交付计划必须包含：
  1. 医学筛查建议
  2. 动态热身与静态拉伸提示
  3. 动作技术优先于负重的原则声明
  4. 出现疼痛（非肌肉酸痛）即停止并就医的警示
  5. 标准的医疗免责声明
