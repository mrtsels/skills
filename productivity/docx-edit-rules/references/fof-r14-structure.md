## 常见替换模式

### 日期替换
```python
# 检查时间在 doc.paragraphs[5]，不在 table 内
for pi, p in enumerate(doc.paragraphs):
    if "检查时间" in p.text:
        for r in p.runs:
            if r.text == "3": r.text = "6"     # 3月→6月
            elif r.text == "31": r.text = "30" # 31日→30日
```

### 持仓明细追加（不离段）
```python
# 不要写入 P11（会新增段落结构）
# 续在 P10 最后一个 run
p10.runs[-1].text = p10.runs[-1].text + "\n" + holdings_text
```

### 增长率 = (新净-旧净)/旧净
```python
# 从 Q2 和 Q1 估值表取 单位净值
# NAV growth: (val_q2 - val_q1) / val_q1
# 如天勤：(3.1181 - 3.5752) / 3.5752 = -12.78%
```
